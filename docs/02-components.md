# 02 · 组件拆解：悬浮卡与详情页

## A. 悬停毛玻璃卡片（Hover Card，桌面端）

**位置**：`app/js/views/map.js → showHover()`，样式 `.hovercard`。
**触发**：Canvas 命中测试（`map.js → hit()`）返回 `unit | spot` 标记。
**定位**：跟随标记屏幕坐标，`translate(-50%, calc(-100% - 10px))`，底部小箭头指向标记。

**毛玻璃使用约束**：`.glass` 类只出现在——地图浮层（进度卡 / 筛选条 / 图例 / 悬停卡 / 缩放控件）与底部 Sheet。卡片内部内容一律使用原生不透明卡片（`--bg-elevated`）+ 分组列表，避免多层模糊叠加降低可读性。

### A1. 家庭记录悬停卡（信息降噪 —— 只保留 7 个元素）

```
┌────────────────────────────┐
│ 西湖的春天                  │  ← 地点（加粗）
│ 2024年4月4日 · 2 次旅行      │  ← 日期 + 聚合次数
│ ┌────────────────────────┐ │
│ │      代表照片（1 张）     │ │  ← 优先取精选第 1 张
│ └────────────────────────┘ │
│ [爸][妈][雨]   16 张  查看 › │  ← 成员头像 · 照片数 · CTA
└────────────────────────────┘
```

明确**不放**：感想正文、完整成员列表、行程路线、天气、评分、广告位。
CTA「查看旅行」点击 → 单次旅行直接进 `#/trip/:id`；多次旅行进 `#/unit/:id`。

### A2. 推荐景点悬停卡

```
┌────────────────────────────┐
│ 八达岭长城                  │
│ 北京市 · 未打卡              │
│ 世界文化遗产，最经典的登城段… ›│
└────────────────────────────┘
```

### A3. 移动端不使用悬停卡

`isMobile()`（宽度 ≤860 或 coarse pointer）时悬停卡永不出现，命中改弹底部 Sheet，内容与 A1/A2 一致，底部主按钮为 Sheet 专属操作（如「标记为已打卡」）。

## B. 旅行详情页组件拆解（`#/trip/:id`）

```
TripDetail
├── NavbarBack                左上角「‹ 返回地图」——回到进入本页的 Tab（地图/时间线/…）
├── Hero                     代表照片 + 地点名 + 标题 + 日期区间
├── InfoGroupCard            原生分组列表：地点/日期/创建者(角色徽章)/可见性
│   └── EditEntry           （创建者或 OWNER 可见）标题/日期/地点编辑 Sheet
├── PhotoWallCard            响应式方形网格 photo-wall
│   ├── PhotoCell           缩略图 + 上传者角标 ★ + 我的精选序号 + ☆/★ 快选按钮
│   ├── UploadButton        （≥MEMBER）压缩 → EXIF 剥离 → IndexedDB
│   └── ManageSheet         批量删除（仅自己的照片或 OWNER）
├── MyBestSection            「我的最佳照片」最多 3 张 —— 选片权归个人
│   ├── PickSlot ×3         缩略图 + 序号 + 移除 ✕；空槽显示「第 N 张」
│   ├── ReorderControls    ↑/↓ 排序（写入 order 1..3）
│   ├── RepickSheet        全量重选（超 3 张即时拒绝 + 服务端二次校验）
│   └── PKHelperSheet      对比 PK：两两点选 → 累计得分 → Top3 建议 → 本人确认
├── FamilyPickAggregate      只读聚合所有成员的精选（小图 + 成员名 + 序号）
│                            明确不做「全家统一评选」，不显示全家票选
├── ThoughtsGroup            每位成员独立感想
│   ├── MyThoughtRow        可编辑（Sheet，多行文本）——仅自己的
│   └── OthersThoughtRow    只读；A 不可编辑 B 的感想（rules 强制）
├── NearbySpotsCard          同城 + <20km 推荐景点列表
│   └── SpotSheet           推荐理由 / 数据来源 / 打卡或取消 / 关联本次旅行
└── DangerZone               删除旅行（二次确认 Sheet，危险样式）
```

**权限驱动的组件可见性**（同一套 `can()` 结果）：

| 组件 | OWNER | MEMBER | VIEWER |
|------|:--:|:--:|:--:|
| 照片墙浏览 / 感想阅读 / 聚合精选 | ✓ | ✓ | ✓ |
| 上传照片 / 我的感想编辑 / 我的选片 / 打卡 | ✓ | ✓ | ✗ |
| 编辑旅行 / 删除自己的照片 | ✓ | ✓（仅自己的） | ✗ |
| 删除他人旅行 / 删除他人照片 | ✓ | ✗ | ✗ |

## C. 其他关键组件

| 组件 | 文件 | 说明 |
|------|------|------|
| `createMap()` | `ui/map.js` | Canvas 渲染：省级底图 → 点亮填充 → 照片气泡（正圆）/ 推荐水滴（pinPath 倒立水滴）→ 南海诸岛占位框；滚轮/双指缩放、拖拽、命中测试（水滴按线段命中）、悬停回调 |
| `navbarBack` | `main.js` | 详情页左上角「‹ 返回XX」：记录最近访问的 Tab，点击回到来源 Tab（旅行/同城聚合/搜索/设置均可用） |
| `memberSheet` | `views/family.js` | 成员编辑：姓名 / 家庭关系（本人或创建者）+ 角色分段选择（仅创建者）+ 家庭贡献统计 + 移出家庭 |
| `sheet()` | `ui/kit.js` | 毛玻璃底部 Sheet，Esc/scrim 关闭，桌面自动居中为 560px 卡片 |
| `sheet` 移动端手势 | `--ease-spring` | 打开 translateY(100%→0)，spring 曲线；`prefers-reduced-motion` 时 1ms |
| `chipScroll` | `views/map.js` | 筛选条：模式/图层/成员/年份，横向滚动 |
| `ring` / `bar` | CSS conic-gradient | 点亮进度环与进度条 |
| `progressCard` | `views/map.js`（地图）/ `views/family.js` | 「已点亮 28/333 个地级市」+ 副行（含直辖市/特别行政区口径） |
| `emptyState` / `errorState` / `skeleton` | `ui/kit.js` | 空/错误/加载骨架 |
| `photoViewer` | `ui/kit.js` | 全屏照片查看（点按关闭） |

## D. 图层视觉规范（家庭 vs 推荐，严格区分）

| 维度 | 家庭记录图层 | 推荐必打卡图层 |
|------|------------|--------------|
| 形状 | **正圆**（照片气泡） | **倒立水滴**（圆头 + 朝下尖端，pinPath）：未打卡/已打卡同形 |
| 填充 | 实心照片（裁切）+ 琥珀描边 | 未打卡：12% 灰底；已打卡：绿色实心 + 白勾 |
| 描边 | 2.5px 白色实线 | 未打卡：1.4px 灰色虚线（dash 3/2.4）；已打卡：1.6px 白环 |
| 光晕 | 琥珀柔光 | 轻投影（6px / 0.2 黑） |
| 悬停放大 | +3px（呼吸感） | ×1.3 |
| 图例 | 「家庭记录（照片气泡）」 | 「推荐·未打卡（水滴）/ 推荐·已打卡（水滴）」 |
| 筛选 | 已点亮/未点亮/成员/年份 | 全部/未打卡/已打卡 |
| 命中区域 | 圆形 r+6 | 沿「圆头→尖端」线段的 11px 管道（覆盖整个水滴） |
