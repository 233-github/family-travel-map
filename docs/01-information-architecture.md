## 1. 导航骨架

| # | Tab | 图标 | 说明 |
|---|-----|------|------|
| 1 | 地图 | 🗺️ | 主页，中国地图 + 点亮进度 + 双图层 |

## 3. 分层结构（省 / 市 / 区县）

- **底图（二选一，设置 → 地图底图决定）**：
  - **官方底图**：天地图（tianditu.gov.cn）Web Mercator 瓦片，`vec_w` 矢量底图 + `cva_w` 中文注记，
    低饱和滤镜呈现；自带审图号，地图左下角显著标注「审图号 + © 天地图 自然资源部」。
    支持 z2–z18 缩放下钻到城市级街区；Token 可在设置页填写，或由 NAS 环境变量 `TIANDITU_TOKEN` 全家统一下发。
  - **示意底图（降级）**：未配置 Token 时使用简化省级行政区底图，并显示「非正式」提示，
    仅供本地开发与演示。
- **主页默认显示全国**：省级行政区低饱和底图 + 已点亮地级行政区照片气泡（正圆）。
- **推荐必打卡图层**：未打卡 / 已打卡统一使用**倒立水滴**标记——未打卡为灰度虚线水滴，
  已打卡为绿色实心水滴 + 白勾；与家庭记录的正圆气泡形状严格区分。
- **缩放 > 4x**：已点亮单元显示琥珀色浅填充与描边（省 → 市 下钻可视）。
- **缩放 > 5x**：地图绘制未点亮城市名标签，辅助定位。
- **点击已点亮单元**：进入单元页（同城多次旅行聚合）；移动端先弹底部 Sheet。
- **区县级**：`placeLabel` 字段记录具体地点（如「西湖景区」），在单元页与详情页显示；
  MVP 不做区县多边形（数据体积原因），生产可按同一 `build_units.py` 流程扩展。

## 4. 状态设计（空 / 加载 / 错误）

| 场景 | 处理 |
|------|------|
| 首次启动 | 生成演示数据（程序化占位图，明确标注「占位图」） |
| 空地图（无旅行） | 悬浮卡隐藏，进度 0/333；空状态文案引导去家庭页创建 |
| 无照片 | 照片墙空状态 + 上传按钮（受权限控制） |
| 无感想 | 成员行显示「尚未写下感想」；我的感想可一键「写下」 |
| 推荐全点亮 | 清单页空状态「清单已全部点亮」 |
| 地理数据加载失败 | Toast 提示需通过 HTTP 打开（file:// 协议 fetch 受限） |
| 权限不足 | 按钮 disabled + 说明文案；操作被拒时 Toast 显示 rules 的拒绝原因 |
| 服务端校验失败 | 422 → Toast 显示服务端原文（如「每人每趟最多 3 张…」） |

## 5. 关键流程

**创建旅行（点亮城市）**：家庭页 → 创建新旅行 → 搜索城市（支持省名）→ 显示「已点亮，将聚合为多次旅行」提示 → 选中即创建并跳详情。

**打卡推荐景点**：地图水滴点击 / 清单页条目 → 详情 Sheet → 「标记为已打卡」→ 可关联同城市旅行记录 → 地图水滴变为绿色实心 + 白勾。

**编辑成员资料**：家庭页点按成员行 → 编辑 Sheet（姓名 / 家庭关系，本人或创建者可改；角色分段选择仅创建者可见）→ 保存后全站成员展示同步。

**成员增删**：
- **添加成员**：家庭页「＋ 添加成员」（仅创建者）→ Sheet 填姓名 / 家庭关系 / 角色（创建者 / 成员 / 仅查看，附权限说明）→ 添加后立即可在成员列表、地图筛选、感想署名中可见。
- **邀请码加入**：家庭页「用邀请码加入家庭」→ 输入 6 位邀请码 + 姓名 → 以「成员」身份加入（模拟其他设备/家人加入同一家庭）。
- **移出家庭**：成员编辑 Sheet →「移出家庭」→ 二次确认（列出该成员的内容数量）→ 成员身份移除，**其旅行/照片/感想/精选保留**，界面署名降级为「已退出成员」；不能移出创建者，不能移出自己。

**返回**：任意详情页（旅行 / 同城聚合 / 搜索 / 设置）左上角「‹ 返回XX」→ 回到进入前的 Tab，地图保持筛选与缩放。

**选片**：详情页照片墙 ☆/★ 快选（满 3 张拒绝）→ 替换/重选 Sheet → 照片 ≥4 张时提供「对比 PK 帮我选」（两两对比累计得分，仅作建议，本人确认）。

**导出**：时间线页 → 导出家庭旅行册（自包含 HTML，可打印 PDF）/ 导出时间线长图（PNG）。
